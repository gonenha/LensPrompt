# גרסאות תסריט וחיבור לבינה

במסך הספרייה בוחרים **הגדרות**, בוחרים ספק פעיל ופותחים את הגדרות OpenAI, Gemini או Claude. מזינים מפתח API אישי, שומרים ובודקים גישה למודל. אפשר לשמור מפתח לכל ספק; בקשת יצירה נשלחת רק לספק הפעיל.

המפתחות נשמרים ב־Keychain עם `WhenUnlockedThisDeviceOnly`, ללא סנכרון iCloud. הם אינם נשמרים בקובצי התסריטים, בהעדפות או בקוד. החיבור ישיר לכתובות HTTPS הרשמיות, עם סירוב להפניות, ללא מטמון וללא ניסיון חוזר אוטומטי. מחיקת מפתח באפליקציה אינה מבטלת אותו בחשבון הספק. החיוב נעשה בחשבון ה־API האישי, בנפרד ממנוי הצ׳אט.

בתסריט בוחרים **יצירת גרסאות עם בינה**. נשלחים הכותרת, הטקסט ונקודות הדיבור בלבד, עד 20,000 תווים יחד. גם נקודות בלבד נתמכות. לא נשלחים סרטונים. הבקשה מחזירה שלושה סגנונות: דינמי וקצבי, סיפורי אמפתי, מקוצר וממוקד; בכל אחד טקסט לגלילה וארבע נקודות. בודקים את הניסוח והעובדות ושומרים את שלוש הגרסאות יחד. כל אחת נפתחת בעורך הרגיל, עם העתקה, תרגול, צילום וטייקים משלה. הגרסאות מחוברות למקור לפי מזהה, ולא לפי כותרת. יצירה חוזרת מוסיפה גרסאות ואינה מחליפה עריכות קודמות.

המקור נשמר. תגובה חלקית, חסרה או חסומה אינה נשמרת. ביטול מפסיק את ההמתנה והבקשה המקומית; ייתכן שהספק כבר עיבד את הבקשה וחייב עליה. יש לבדוק מחירים ומכסה אצל הספק לפני שימוש. אין חיוב או בקשת יצירה בפתיחת ההגדרות.

בדיקת החיבור מבקשת מידע על המודל בלבד; הרשאות יצירה, מכסה ואיכות התוצאה נבדקות בבקשת יצירה אמיתית. בדיקות הפיתוח משתמשות במפתחות מדומים ובתגובות קבועות, ואינן מוכיחות חיבור לחשבון אישי. משוב צילום וניתוח וידאו נשארים שלב נפרד.

## תיעוד ספקים ששימש למימוש

- [OpenAI Responses ו־Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses), [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna).
- [Gemini GenerateContent Structured Output](https://ai.google.dev/gemini-api/docs/generate-content/structured-output?hl=en), [קטלוג מודלים](https://ai.google.dev/gemini-api/docs/models?hl=en).
- [Claude Structured Outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs), [קטלוג מודלים](https://platform.claude.com/docs/en/models/overview).

ברירות המחדל נבדקו בתיעוד ב־19 באוקטובר 2026: `gpt-6-luna`, `gemini-3.5-flash-lite`, `claude-haiku-5-5`. זמינות בפועל תלויה בחשבון; אפשר לשנות את שם המודל בהגדרות.
