# Dark Studio

Approved visual direction: a quiet charcoal studio with high-contrast Hebrew typography, lime primary actions and coral recording controls.

| Role | Color |
|---|---|
| Background | #171916 |
| Surface | #252822 |
| Text | #F2F1E8 |
| Secondary | #A6ABA0 |
| Accent | #D6E787 |
| Recording | #EF7066 |
| Divider | #3A3E35 |

Library, text editor, four manual speaking cues, setup and both recording modes share the same system. Existing takes, results, errors and permission states follow it too. Keep controls >=48pt, support RTL and wrapping. Prompt size/width/opacity stay user-controlled. Cues never advance automatically. Approximate sound pacing is not speech recognition. Media and scripts stay on-device.
